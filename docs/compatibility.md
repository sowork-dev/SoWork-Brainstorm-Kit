# 相容性與測試邊界

[English](../locales/en/docs/compatibility.md) · 繁體中文

- v0.3.0 分開提供英文與繁中單檔包，預設 AI 名人共創；仍須使用者明確要求工具採用。
- ChatGPT 網頁端完整多輪帶領、repo URL 自動取檔與真實帳號操作：尚未完成驗收。
- 其他 AI 工具：依帳號、附件和讀取能力測試，不保證所有工具相同行為。
- 原生 Skill／Plugin：本版本未提供。
- 內附九位是編輯定義的虛構角色，不是九個獨立代理；人物庫不是自選角色的上限。

靜態測試、作者虛構示例、模型沙盒試跑與真實平台測試必須分開記錄，不互相替代。
