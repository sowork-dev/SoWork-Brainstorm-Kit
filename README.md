# CJ Brainstorm Kit｜AI 動腦會議主持包

**先確認目的 → 推薦方法 → 用戶確認 → 逐輪帶領 → 收斂成果。**

把方法交給 AI，讓它引導你思考，而不是一次代寫全部答案。可供個人使用，也可讓真人主持人配合團隊使用。

> **v0.1.0 公開試用稿。** 包含 31 張方法卡（含相近變體）。檔案與來源檢查不等於主持品質驗證；目前尚未完成 ChatGPT 網頁端完整對話實測。不是原生插件，也不保證只貼 repo 網址便能自動載入全部檔案。

## 一分鐘開始

1. [下載單一 START-HERE.txt](https://github.com/contentincubator2-ops/cj-brainstorm-kit/releases/download/v0.1.0/START-HERE.txt)；也可開啟 repo 中的 [START-HERE.txt](START-HERE.txt) 並使用檔案下載功能。
2. 在支援讀取文字附件的 AI 對話中上傳該檔；若不支援附件，依該工具能力貼上全文或分段提供，不假裝已完成載入。
3. 貼上以下啟動句：

```text
請讀取附件，依照其中的主持規約帶我開一場動腦會議，不要只摘要內容。
先確認我的目的與參與方式，推薦適合的方法並說明理由；等我確認後，才逐輪帶領。
每次只問一個關鍵問題並等待回覆，不替我虛構答案、真人投票或已經過的時間。
我今天想處理的題目是：＿＿＿＿。
```

不知道題目也可以先說「我想釐清要解決什麼問題」，讓主持人先協助定題。

## 只想貼 GitHub 網址？

可以提出讀取要求，但**要先確認工具實際讀到了內容**。若只看到 README、無法開啟方法檔或缺少讀取工具，請改用單檔附件。

```text
請讀取這個 repo 的 FACILITATOR.md、methods/index.md，以及推薦方法的完整方法卡。
若無法取得必要檔案，請直接告訴我，不要假裝讀過。
先確認我的目的，推薦一個主方法並等待我同意，再逐輪帶領。
```

## 有哪些方法？

- 1 分鐘想十個策展人：依提出的練習名稱編寫，細節待原作者核對。
- 635：六位真人、每人每輪三筆、每輪五分鐘的接力規格。
- 另依 Asana 29 項索引編寫方法卡，涵蓋問題釐清、發散、角色視角、團體接力、方案評估與體驗檢查。
- 31 張卡不是 31 種互不重疊的理論；例如 635 屬腦力書寫變體。

查看 [完整方法索引](methods/index.md)、[方法來源與校正](SOURCES.md)。六頂思考帽依方法所有者的官方說明校正為同一時間全組採同一思考模式，不將六人固定分為六種人格。

## 專案內容

- [主持規約](FACILITATOR.md)：需求釐清、推薦條件與互動狀態。

- `START-HERE.txt`：包含主持規約、索引與全部卡片的單檔下載版，不依賴 AI 爬完整個 repo。
- [會議準備](templates/meeting-brief.md)、[暫停狀態](templates/session-state.md)、[成果格式](templates/outcome.md)。
- [虛構示範](examples/solo-session.md)：展示預期互動節奏，不是平台測試紀錄。
- [使用說明](SETUP.md)、[測試狀態](tests/README.md)、[貢獻方式](CONTRIBUTING.md)。

## 維護與檔案檢查

需 Python 3.10+，僅使用標準函式庫：

```sh
python3 scripts/build.py
python3 scripts/validate.py
```

建置工具產生文字包；檢查工具驗證方法數量、檔案引用、下載包一致性及常見敏感資料模式。**它們不是 AI 品質測試或 ChatGPT 實測。**

## 邊界與資料保護

- AI 不是真人團隊；單人與 AI 的角色模擬不等於六人 635 或真人共識。
- 純文字指令不會自動授權工具、進行背景倒數、安排後續工作或提供跨對話記憶。
- 不要將真實客戶資料、參與者個資或會議逐字稿貼到公開 Issue／PR。
- 本專案不是引用方法的官方或認證教案，不暗示來源機構背書。
