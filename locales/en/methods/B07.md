## B07 | Gap Filling (also called Gap Analysis)

**When to use / Suggested time**: You know the goal but are unsure how to bridge the gap; 15–20 minutes.

**Opening**: “Describe where we are and where we want to be, then identify what is missing in between.”

**Process**: Describe the current state → define an observable target state → list the gaps between them → propose actions to bridge each gap → choose the first action you can take.

**Follow-up / Output**: “Is the gap a lack of resources, skills, or information, or a process that does not work?” Produce a current state–target state–gap–action list.
