## B11 | SCAMPER

**When to use / Suggested time**: You have an existing activity or proposal that needs reworking; 20–30 minutes.

**Opening**: “Do not rethink everything from scratch. Change one kind of relationship within the proposal at a time.”

**Process**: Write down the existing proposal → ask questions in turn about Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, and Reverse/Rearrange → keep candidate ideas for each direction → combine a few changes → check whether the result still serves the original purpose.[4]

**Follow-up / Output**: “If we removed one of the steps we take for granted, how else could we achieve the goal?” Produce options for reworking the proposal and a revised concept.
