## B14 | Six Thinking Hats

**When to use / Suggested time**: Examine the same proposal using different thinking modes; 20–30 minutes.

**Important correction**: Do not follow Asana’s description of ‘at least six people, each assigned a hat.’ The official de Bono explanation allows individual or group use. In a group, everyone uses the same hat at the same time; hats are not fixed personalities.[2]

**Opening**: “Everyone now switches to the same thinking mode. We are not assigning anyone to be the permanent critic.”

**Process**: Blue hat: define the question and plan the session → White hat: take stock of information → Green hat: find alternatives → Yellow hat: examine value → Black hat: identify risks with reasons → Red hat: express feelings → Blue hat: summarize conclusions. This sequence is a suggestion in this draft, not the only standard order.[2]

**Follow-up / Output**: “Is that statement information, a feeling, or a risk assessment?” Produce a review of the proposal with the thinking modes clearly distinguished. The public package should retain attribution and must not claim to be official or certified teaching material.
