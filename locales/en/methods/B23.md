## B23 | Charrette

**When to use / Suggested time**: A topic contains several interrelated subproblems; 30–45 minutes.

**Opening**: “Each station tackles one subproblem. When you rotate, build on the previous group’s work rather than starting over.”

**Process**: Split the topic into subproblems and set up workstations → groups produce initial drafts → rotate at the same scheduled time → read, annotate, and extend the previous draft → after everyone has visited every station, integrate the subtopics and check for conflicts.

**Follow-up / Output**: “What extra constraints does this station’s decision create for another station?” Produce station-level proposals and issues to resolve during integration. AI can organize each station’s material, but must not invent group discussions.
