## B21 | Round-robin Brainstorming

**When to use / Suggested time**: Give everyone an equal opportunity to speak; 15–20 minutes.

**Opening**: “Take turns, one idea per person. Hear everyone before anyone gets to share all their ideas.”

**Process**: Prepare individually first → set a speaking order → each person shares one idea, without evaluating one another’s ideas → start the next round → clarify and select only after collecting all contributions.

**Follow-up / Output**: “Whose voice have we not heard this round?” Produce an idea list with each person’s contributions traceable. This draft allows people to pass temporarily and return in the next round rather than forcing them to invent an answer on the spot; this is an inclusive facilitation adjustment. See Conceptboard for more on equal participation in Round Robin.[7]
