## B09 | Collaborative Brainwriting

**When to use / Suggested time**: Ideas need time to settle, and people do not need to be online together; keep contributions open for one agreed working day.

**Opening**: “You can come back later to add ideas, but leave your own original perspective before the deadline.”

**Process**: Announce the prompt and deadline → set up a shared writing space → each person contributes independent ideas first → then read and build on others’ contributions → after the deadline, the facilitator compiles the material and asks members to confirm it.

**Follow-up / Output**: “After some time away, what would you add or revise?” Produce an evolving document with traceable authorship and revisions. Promise anonymity only if the tool actually supports it.
