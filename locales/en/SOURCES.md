# Method sources and editorial notes

The repository follows a public method index while authoring its own openings, facilitation steps, follow-ups, and output formats. It is not a verbatim translation of source websites or an official/certified course from any cited institution.

- Asana supplies the B01–B29 index.
- Six Thinking Hats is corrected against de Bono's official summary: it can be used alone, and groups use the same thinking mode at the same time. Hats are not fixed personality assignments. The suggested order is editorial, not the only valid sequence.
- 6-3-5 filled slots are not a count of unique, effective ideas. Solo simulation is not a formal six-human session.
- A01 is a draft based on a warm-up name supplied by CJ Wang. Original-course details remain unconfirmed; do not claim the full workshop has been reproduced.
- Referencing third-party names, trademarks, websites, or teaching material does not imply endorsement or grant rights to those materials.
