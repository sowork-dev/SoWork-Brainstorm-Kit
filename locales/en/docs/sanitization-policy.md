# Public-material policy

Publish only shareable methods, original facilitation text, public references, empty templates, and clearly fictional demonstrations. Do not include original private workshop files, participant records, client cases, runtime environments, login screenshots, credentials, real conversations, or internal operation logs.

If a platform test is blocked, publish only a necessary status explanation. Do not substitute fictional demonstrations or static checks for real platform evidence. A historical per-file audit must use repository-relative paths and exclude local execution metadata.
