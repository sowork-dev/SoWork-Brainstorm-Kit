# Compatibility and evidence boundaries

Separate English and Traditional Chinese text packs are provided. The user must explicitly ask the chosen tool to read and use one.

- Complete ChatGPT web multi-turn acceptance and automatic repository-URL retrieval remain unpassed.
- Other platforms depend on actual account, file-reading and retrieval capabilities; no universal compatibility claim is made.
- This version is not a native Skill/Plugin installation.
- The nine profiles are fictional editorial roles, not nine independently running agents. The library is not the limit on custom people.
- Authored examples, static packaging tests, sandbox trials and real platform tests are separate evidence classes.

The [recorded open-cast trials](../../../tests/OPEN-CAST-TRIALS.zh-en.md) contain eight actual model responses with full text supplied through a provider adapter. They do not establish website attachment or repository retrieval behavior.

The full human-teaching protocol stays in the repository as opt-in material; default packs include a compact teaching summary and mode labels before every reference card. This mitigates prompt conflict but is not proof of model behavior.
