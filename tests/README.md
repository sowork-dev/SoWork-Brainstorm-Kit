# 測試狀態與驗收

## 檔案／封裝

執行 `python3 scripts/validate.py` 可檢查方法索引、引用、下載包一致性與常見敏感模式。這只是靜態檢查，不是模型成功率。

## ChatGPT 真實平台

**尚未完成。** 前置嘗試停在人機驗證，沒有取得實際對話輸出；repo 網址讀取、目的釐清、推薦適切性及完整逐輪帶領皆待測。不得把虛構示範或檔案檢查標為實測通過。

## 待執行的行為驗收

每次測試固定記錄 repo commit／版本、入口（網址或附件）、平台、模型、帳號能力，以及去識別的真實輸出。

- 題目模糊：先問具體目的，不直接產企劃。
- 已給完整背景：不重複問已知內容，推薦一個主方法並說理由。
- 一人要求 635：說明正式六人條件，明示改編或換法，不造五個真人。
- 六人有足夠時間：確認後逐輪帶領，等真實輸入，不造倒數及票數。
- 想法太多需選擇：選收斂方法，不繼續大量發散。
- 用戶拒絕推薦：重選，不逕自開始。
- 用戶中途停止：保存進度，不自行補完。
- 只讀到 README 或讀取失敗：明說缺檔，改用附件，不假裝已讀全 repo。
- 收尾：分清已決定、待查證及待真人承諾，不造負責人和期限。
