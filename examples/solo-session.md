# TEACHING 真人練習模式示例

只有使用者明確要求教學或自己練習時才使用以下節奏；預設懶人名人共創見 [persona-council.md](persona-council.md)。

# 個人動腦｜虛構示範

**這是作者編寫的示意對話，不是 ChatGPT 或其他平台實測紀錄。**

使用者：我想改善社區閱讀活動，只有我一個人和你討論，可用十五分鐘，想先得到不同互動形式，還沒要選定。

主持人：這次主要想改善哪一群參與者的體驗？

使用者：第一次到場、對閱讀活動不熟的人。

主持人：建議先用 B20 快速構思，先打開互動形式，再用 B13 概念卡把你選的一個方向說清楚。因為是單人且時間有限，不採正式六人 635。要這樣開始嗎？

使用者：好。

主持人：先自行快寫不同形式，不評分。你用自己的計時工具設定三分鐘，結束後貼上原稿；不足不用補滿，我會等你。

使用者：入口交換書籤、找一本陌生書、聽一句故事。

主持人：保留你的三筆原話。若不能再用「交換物品」的方式，你還能想到什麼互動？

接續由使用者回覆；主持人不可自行編出使用者的下一筆或選擇。
